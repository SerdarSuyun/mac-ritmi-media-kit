# Maç Ritmi Digital Media Kit V2.1

Sponsorlu içerik paketleri, Özel Prodüksiyon ve 16 temsili reklam uygulaması.

Canlı site: https://serdarsuyun.github.io/mac-ritmi-media-kit/index.html

## Geliştirme

Node.js 22+: npm run check, npm run build, npm run preview.

İçerikler src/data içindeki JSON dosyalarından yönetilir. Aylık sponsorluk paketleri mevcut futbol içeriklerine marka entegrasyonudur; markaya özel bağımsız video yalnız Özel Prodüksiyon kapsamında sunulur.

GitHub Pages kök dizini ve dist içeriği aynı build ile güncellenmelidir. Kamuya açık fiyatlandırma bulunmaz.
